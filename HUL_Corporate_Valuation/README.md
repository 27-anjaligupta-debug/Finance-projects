 HUL Corporate Valuation & Intrinsic Value Assessment

 Project Objective

To examine the valuation of Hindustan Unilever Limited (HUL) using the Excess Abnormal Book Value (EABV) approach and understand how financial assumptions influence the estimated value of a business.

 Analytical Approach

The project uses an Excel-based valuation model to organise financial inputs, apply the selected valuation methodology, and assess the resulting estimate. The underlying calculations and assumptions must be reviewed before drawing conclusions.

 Key Areas of Analysis

- Valuation methodology and assumptions
- Financial inputs and supporting calculations
- Interpretation of estimated intrinsic value
- Model limitations and sensitivity to assumptions

 Key Findings

Numerical findings and financial interpretations will be added after validating the calculations in the supporting workbook.

 Learning Outcomes

This project develops practical understanding of corporate valuation, spreadsheet-based financial analysis, and the importance of connecting numerical outputs to business interpretation.

 Supporting File

- [HUL Corporate Valuation.xlsx](../HUL%20Corporate%20Valuation.xlsx)

 Limitations

The valuation estimate depends on the model's inputs, assumptions, and calculation structure. It should not be treated as a definitive market price or investment recommendation without further validation.
